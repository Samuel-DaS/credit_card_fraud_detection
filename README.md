# 🪙 Credit Card Fraud Detection (Machine Learning Project)

## 📘 Overview
This project uses **machine learning** to detect fraudulent credit card transactions using the [Kaggle Credit Card Fraud Dataset](https://www.kaggle.com/mlg-ulb/creditcardfraud).

The goal is to train a model that can identify **fraudulent (1)** vs **legitimate (0)** transactions based on anonymized transaction data.

---

## 🧰 Tools Used
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn (Logistic Regression, Evaluation Metrics)  

---

## ⚙️ Project Steps
1. **Data Exploration:** inspected data shape, types, and missing values  
2. **Visualization:** histograms, boxplots, correlation heatmap, and class balance  
3. **Feature Preparation:** separated features (X) and labels (Y)  
4. **Model Training:** (up next) Logistic Regression model to predict fraud  
5. **Evaluation:** accuracy, confusion matrix, and ROC curve  

---

## 📊 Dataset Info
- Total transactions: 284,807  
- Fraud cases: 492 (≈0.17%)  
- Highly imbalanced dataset  
- Features: 30 (V1–V28 are PCA components, plus Time and Amount)
